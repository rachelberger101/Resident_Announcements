## Quick Reference: Throwing Exceptions in Code

```csharp
// Client input validation
throw new ArgumentException("Message", nameof(parameter));

// Missing required data
throw new ArgumentNullException(nameof(variable));

// Logic error
throw new InvalidOperationException("Cannot perform operation in current state");

// Data format issue
throw new FormatException("Invalid date format");

// Resource lookup failed
throw new KeyNotFoundException("Resource with key 'X' not found");

// Request took too long
throw new OperationCanceledException("Operation timed out");

// Access denied
throw new UnauthorizedAccessException("Access denied");

// Unexpected error (wrapped from lower layer)
throw new InvalidOperationException("Operation failed", innerException);
```

**Result:** Middleware catches ? Maps to HTTP status ? Logs ? Returns error response

## Common Patterns & Examples

### Pattern 1: Input Validation
```csharp
public async Task<IActionResult> Get(string authorityCode)
{
    if (string.IsNullOrWhiteSpace(authorityCode))
        throw new ArgumentException("Cannot be empty", nameof(authorityCode));

    // ... rest of code
}
```
**Result:** 400 Bad Request

### Pattern 2: Resource Not Found
```csharp
var result = await service.GetAsync(id);
if (result == null)
    throw new KeyNotFoundException($"Item {id} not found");

return Ok(result);
```
**Result:** 404 Not Found

### Pattern 3: Exception Wrapping
```csharp
try
{
    // ... database operation
}
catch (Exception ex)
{
    throw new InvalidOperationException("Failed to fetch data", ex);
}
```
**Result:** 500 Internal Server Error (wrapped exception)

### Pattern 4: Authorization
```csharp
if (!user.IsAuthorized)
    throw new UnauthorizedAccessException("User lacks permissions");
```
**Result:** 401 Unauthorized
